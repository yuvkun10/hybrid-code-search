# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. You will get a reply within a few days, and a fix or a clear answer as soon as the issue is confirmed.

## Supported versions

Only the latest version on the default branch receives fixes.
